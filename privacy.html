Privacy Policy

Last updated: 2026-11-21

CTP2026 is a personal tool used only by its owner to access the owner's own Google Tasks through the Google Tasks API (scope: https://www.googleapis.com/auth/tasks).

Data accessed

Task lists and tasks (titles, notes, due dates, status) in the signed-in Google account.

How data is used

Data is read and modified only when the owner runs the tool, solely to list, add, edit, complete or delete the owner's own tasks.

Storage and sharing

The access token is stored only on the owner's own computer. No data is sent to, stored on, or shared with any server or third party operated by the developer. No data is sold or used for advertising.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
